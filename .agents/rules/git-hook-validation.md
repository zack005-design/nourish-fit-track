# Commit Name Validation Boundary

## Context

Enforce this rule directly before executing any automated Git commit to ensure the custom names generated by the AI conform to professional standards and strict character boundaries.

## Validation Rules

- **Length Constraint:** Ensure your custom commit message string does not exceed 72 characters in total length. Keep it concise but descriptive.
- **Structural Check:** Verify that the message begins with a valid semantic prefix (e.g., `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`).
- **Lowercase Enforcement:** Write the description following the semantic prefix entirely in lowercase letters (e.g., use `fix: update button styling`, NOT `fix: Update Button Styling`).
- **No Punctuation:** Do not include a trailing period or ellipsis at the end of your custom commit message.
